# 토너먼트

학생 봇을 모아 **스위스 예선 → 더블 일리미네이션 본선** 을 한 번에 돌리는 프로그램이다. 모든 판의 리플레이가 남고, 끝난 토너먼트는 zip 하나로 묶어 다른 컴퓨터에서 열 수 있다.

## 1. 프로그램 열기

```bash
python -m wumpus tournament
```

Windows 에서는 저장소 맨 위의 `tournament.bat` 을 더블클릭해도 된다. 브라우저에 프로그램 화면이 열린다 (`http://127.0.0.1:8770`). 검은 창을 닫으면 프로그램이 끝난다.

## 2. 새 토너먼트

1. **봇 폴더**: 학생 봇이 든 폴더를 고른다. 안에 파이썬 파일 `이름.py` 만 학생마다 하나씩 있으면 된다 (폴더로 감싸지 않아도 된다). `이름/main.py` 폴더 모양도 되고, 섞어도 된다. 파일 (또는 폴더) 이름이 팀 이름이 된다. 다른 파일은 무시한다.
2. **봇 확인**: 봇 수, 코드 검사 결과, 걸릴 시간을 보여 준다. 코드 검사에 걸린 봇도 참가하지만 판마다 실격으로 진다.
3. **토너먼트 시작**: 그 순간 **새 맵** (기본 21개) 을 만들고, 봇 코드를 토너먼트 폴더에 복사한 뒤 끝까지 이어서 돌린다.
   - 스위스 예선 (기본 7 라운드): 점수가 비슷한 팀끼리, 이미 만난 상대는 피해서 짝짓는다. 짝마다 맵 하나를 양쪽 진영으로 두 판 (판 승 1점, 무승부 0.5, 홀수일 때 부전승 1점). 순위는 점수 → 상대 점수 합 → 바친 금 합.
   - 본선 시드 = 예선 순위. 대진표는 2 의 거듭제곱 칸이고 (73팀이면 128칸), 남는 칸은 **높은 시드의 부전승**이다. 1·2번 시드는 승자조 결승 전에는 만나지 않는다.
   - 본선 한 경기 = 맵 21개에서 한 판씩 (진영은 번갈아). 이긴 판 수가 많은 팀이 이긴다. 같으면 바친 금 합, 그것도 같으면 높은 시드.
   - 승자조 우승팀이 그랜드 파이널에서 지면 한 번 더 (결승 리셋).
4. 진행 막대와 대진표가 돌아가는 대로 채워진다. **멈추기** 로 멈추고, 나중에 **불러오기 → 이어서 돌리기** 로 이어 간다.

73팀이면 예선 약 500판 (5~10분), 본선 약 3,000판 (30분~1시간) 이다 (CPU 12코어, 봇 한 판 6초 기준).

## 3. 대진표 보기

| 기능 | 하는 법 |
|---|---|
| 이동 · 확대 | 끌기 · 휠, 위의 − / + · **대진표 맞추기** · **보기 초기화** · 전체 화면 |
| 라운드 접기 | 라운드 제목을 누른다. **라운드 모두 펼치기** 로 되돌린다 |
| 팀 찾기 | 검색 칸에 학생 이름. 그 팀의 경기만 밝게, 마지막 경기로 이동, 오른쪽에 걸어온 길 (예선 순위 · 경기마다 점수 · 어디서 탈락했나) |
| 경기 결과 | 상자마다 "몇 대 몇". 이긴 팀은 초록. 누르면 21판의 맵 · 진영 · 승자 · 바친 금 |
| 리플레이 | 판마다 **▶ 보기**. 위의 **이전 판 · 다음 판** 으로 넘긴다 |
| 예선 | **스위스 예선** 탭: 순위표와 라운드마다 상대 · 결과 (누르면 두 판의 리플레이) |
| 최종 순위 | **최종 순위** 탭: 1등 우승 · 2등 준우승 · 3등부터는 패자조에서 늦게 탈락한 차례. 같은 패자조 라운드에서 탈락한 팀은 공동 순위 (예: 5~6등, 9~12등). 숨긴 경기로 정해지는 자리는 `?`, 누르면 그 경기로 간다 |

## 4. 공개 범위

처음 열면 **모든 본선 결과가 숨겨져 있다** (공개 범위: "모두 숨김"). 1 라운드 대진만 보이고, 경기 결과와 그 경기에서 올라온 팀 이름은 `?` 로 가려진다. **공개 범위** 에서 "모두 공개", "16강부터 숨김", "4강부터 숨김", "그랜드 파이널부터 숨김" 으로 바꿀 수 있다. 스위스 예선 순위는 늘 보인다 (본선 시드이므로).

- 숨긴 경기를 누르면 **리플레이를 먼저 틀어 볼 수 있다**. 다 본 뒤 **결과 공개** 를 누르면 그 경기의 점수와 다음 경기로 올라간 팀이 드러난다.
- 공개 범위와 공개한 경기는 그 브라우저에 기억된다.

## 5. 다른 컴퓨터에서 열기 (zip)

**zip 내보내기** 를 누르면 토너먼트 폴더 옆에 `<토너먼트 이름>.zip` 이 생긴다. 지금 고른 공개 범위가 받는 사람이 처음 열 때의 공개 범위가 된다.

- 받은 사람은 압축을 풀고 `index.html` 을 크롬 · 엣지로 연다. 설치 · 인터넷이 필요 없다.
- 또는 프로그램의 **불러오기** 에서 zip 을 바로 고른다.
- zip 에는 대진표 · 모든 리플레이 · 맵이 들어 있고, **학생 봇 코드는 들어 있지 않다**. 73팀이면 약 300 MB 다.

## 6. 화면 없이 (명령줄)

```bash
python -m wumpus tournament run 대회폴더 --bots 학생봇폴더 [--maps 21] [--rounds 7] [--jobs 10] [--seed 1]
python -m wumpus tournament pack 대회폴더                 # 모두 숨긴 zip (기본). --hide none 모두 공개 · --hide 8 8강부터
```

`run` 은 멈췄다 다시 부르면 이어서 돌린다. 같은 `--seed` 면 같은 맵 · 같은 대진이 나온다.

## 7. 토너먼트 폴더

| 파일 | 내용 |
|---|---|
| `config.json` | 팀 · 맵 · 설정 |
| `state.json` | 예선 짝 · 대진표 · 모든 판의 결과 (이어서 돌리기에 쓴다) |
| `maps/` | 만들 때 새로 생성한 맵 |
| `bots/` | 시작할 때 복사한 봇 코드 (나중에 학생이 고쳐도 토너먼트는 그대로) |
| `replays/<판>.js` | 리플레이 (압축) |
| `index.html` · `viewer.html` · `data.js` | 대진표 화면 · 리플레이 뷰어 · 화면용 요약 |
