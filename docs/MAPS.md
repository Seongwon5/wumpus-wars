## 3. 새 맵 만들기

```bash
python -m wumpus maps gen my_map --seed 42                 # 무작위 크기 · 대칭
python -m wumpus maps gen big_r --seed 7 --size 28 --sym R  # 28x28, 180° 회전 대칭
```

- `maps/<이름>.json` 으로 저장된다. 바로 `run --map my_map`, `scrim --maps my_map` 에 쓸 수 있다.
- 같은 시드면 같은 맵이 나온다.
- 저장하지 않고 그 자리에서 쓰려면 맵 이름 대신 `gen:42` 를 준다.

생성기가 지키는 것:

- 벽 · 금맥 · 구덩이 · 야영지가 모두 같은 대칭을 따른다.
- 야영지는 네 귀퉁이 근처에 놓이고, 두 야영지는 체비셰프 거리 10 이상 떨어진다.
- 구덩이는 벽 · 금맥 칸 · 야영지 2칸 안에 없다.
- 구덩이는 빈 칸의 약 12% 다.
- 두 야영지는 구덩이를 밟지 않는 길로 이어지고, **모든 금맥**에 구덩이 없는 길로 갈 수 있다. 다만 그 길이 바람 칸 사이로 나 있으면 안전을 증명하기 어렵다. 위험을 언제 감수할지가 봇의 실력이다.

## 4. 맵 파일 형식

```text
{
  "format": "wumpus-map-1",
  "name": "twin_pillars", "w": 20, "h": 20, "sym": "H", "seed": 104,
  "rows":  ["..##..", ...],          // 줄마다 글자: '#' 벽, '.' 그 밖
  "gold":  [[x, y, 양], ...],        // 금맥 칸과 처음 금 양
  "pits":  [[x, y], ...],            // 숨은 구덩이
  "camps": [[x, y], [x, y]],         // 붉은 원정대, 푸른 원정대 야영지
  "wumpus": [[x, y], ...],           // (선택) 웜퍼스 굴. 없으면 맵 가운데에 가까운 한 쌍을 엔진이 정한다
  "gold_sites": [[[x, y], ...], ...] // (선택) 금맥마다 다 캔 뒤 새 금맥이 생길 자리 사슬. 없으면 엔진이 맵 시드로 대칭이 되게 정한다
}
```

`wumpus` 를 적으면 굴을 여러 곳 둘 수 있다 (금이 적고 웜퍼스가 많은 맵처럼). 굴도 대칭이어야 하고, 야영지 둘레 · 벽 · 구덩이 · 금맥 칸에는 두지 않는다.

손으로 맵을 만들 때는 대칭을 꼭 지킨다. `python -m unittest discover tests` 가 `maps/` 의 모든 맵이 대칭인지 확인한다.
